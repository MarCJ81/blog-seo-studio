개인정보 처리 방침

블로그 SEO 스튜디오 · 최종 갱신 2026-11-21

1. 수집하는 개인정보

없습니다. 이 앱은 회원가입·로그인·결제가 없고, 서버로 전송되는 데이터가 없습니다. 입력한 키워드, 원고, 메모, 설정은 모두 사용자의 브라우저 localStorage에만 저장됩니다.

2. 외부 전송

기본 상태에서는 외부 요청이 0건입니다. 사용자가 선택적으로 '프록시 API'를 설정한 경우에만, 입력한 엔드포인트 주소로 키워드 조회 요청과 API 키가 전송됩니다. 이 전송은 사용자가 직접 설정하고 실행한 경우에만 일어납니다.

Pro API 연결(선택). 'Pro AI로 완성 원고 생성'을 쓸 때만, 주제·키워드·메모 등 입력한 내용이 사용자가 고른 제공자(OpenAI·Google Gemini·Anthropic Claude 또는 직접 입력한 자체 서버)로 브라우저에서 직접 전송됩니다. 연결하지 않으면 전송은 없습니다. API 키는 기본적으로 sessionStorage(탭을 닫으면 삭제)에만 두고, '이 브라우저에 기억'을 켰을 때만 localStorage에 남습니다. 키는 요청 헤더로만 나가며 화면·주소·오류 문구에 남기지 않습니다. 팝업의 '연결 해제'를 누르면 저장된 키가 지워집니다.

3. 쿠키·추적

쿠키를 쓰지 않고, 분석 도구·광고 픽셀을 넣지 않습니다.

4. 보관과 삭제

모든 데이터는 브라우저 저장소를 지우면 함께 삭제됩니다. 앱 안에서 키워드·발행 기록을 개별 삭제할 수 있고, 프록시 설정의 '키 삭제'로 저장된 키를 지울 수 있습니다.

5. 제3자 제공

제3자에게 제공하는 데이터가 없습니다. 프록시를 직접 설정한 경우, 해당 요청은 사용자가 고른 서비스로만 갑니다.

6. 문의

이 앱은 정적 파일로 배포되며, 운영자에게 개인정보가 전달되지 않습니다.
