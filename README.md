# 블로그 SEO 스튜디오

한국 블로거가 매달 구독료를 내는 **블라이 · 판다랭크 · 키자드** 흐름을 한 화면으로 묶은 무서버 정적 웹앱입니다. 키워드 경쟁률 계산부터 발행 전 원고 진단, H2 아웃라인·프롬프트, 발행·순위 기록까지 브라우저 안에서 끝납니다.

여기에 **카피라이터·마케팅 심리학 엔진**(8대 트리거 진단, 추상어·공급자어 교정, PAS·BAB·AIDA·4U 도입부)과 **내 구독 AI 원클릭 브리지**(ChatGPT·Claude·Gemini)를 얹었습니다.

- 서버 없음 · 로그인 없음 · 기본 상태에서 외부 요청 0건
- 원고·키워드·메모는 `localStorage`에만 저장
- 라이트/다크 모드, IBM Plex Sans KR, 반응형
- **Pro AI 연결(선택)** — 헤더의 `무료 모드 · API 연결` 배지에서 OpenAI·Gemini·Claude·자체 서버를 연결하면, 구조·프롬프트 탭의 **✨ Pro AI로 완성 원고 생성**이 주제·키워드·메모로 완성 원고를 써서 원고 진단에 바로 넣습니다. 연결하지 않으면 기존 무료 엔진과 내 구독 AI 브리지가 0원·추가 요청 0건으로 그대로 동작합니다. 키는 기본 `sessionStorage`. 엔진: `engines/pro-api-connector.js` · `engines/pro-studio.js`

## 탭 4개

1. **키워드 황금률** — 내장 예시 32개 + 직접 추가 + CSV/TSV 붙여넣기(헤더 자동 인식, PC+모바일 합산). 경쟁률(문서수÷검색량)·포화도·S/A/B/C 등급·추천도(0~100)를 즉시 계산·정렬. 선택형 BYOK 프록시 조회.
2. **원고 진단** — 제목(길이·앞 20자 키워드·반복·특수문자), 본문(공백 포함/제외 글자수, 문단, 장문 벽), 키워드 반복(4~8회 적정, 10회+ 경고), 구조(소제목·리스트·비교표), 위험 표현(과장·의료·금융·단축URL·연락처·복붙), AI 번역체(12계열) 6항목 100점. 본문 하이라이트와 구어체 대안 제시.
   - 아래에 **마케팅 심리학 8대 트리거**(클릭·체류·전환)와 **추상어·공급자어 교정** 패널이 함께 나옵니다.
3. **구조·프롬프트** — 주제·키워드·독자·톤(구어체/전문가/체험후기)으로 **도입부 4종(PAS·BAB·AIDA·4U)**, 제목 후보 5개, H2 5단 아웃라인, 체크리스트·비교표 뼈대, 댓글 질문 3개, 태그 10개, ChatGPT/Claude/Gemini로 바로 보내는 SEO 프롬프트를 생성.
4. **발행 트래커** — 제목·키워드·발행일·점수·상태·메모 기록, 상태 필터/정렬, CSV(UTF-8 BOM)·JSON 내보내기, JSON 가져오기.

## 카피·심리학 엔진

`engines/copy-psych-engine.js` — 의존성 0의 UMD 모듈(`window.CopyPsych`, node는 `require`). 공용 엔진 `packages/copy-psych-engine.js`와 같은 사본입니다.

| 기능 | 내용 |
| --- | --- |
| 8대 트리거 | 손실 회피 · 구체적 숫자(앵커링) · 호기심 갭 · 인지 반전 · 사회적 증거 · 희소성·기한 · 권위·실측 · 초저마찰 CTA. 신호를 찾아 0~100점 |
| 블로그형 묶음 | 같은 점수를 **클릭(curiosity·interrupt·loss) · 체류(anchor·authority·social) · 전환(scarcity·cta)** 로 묶고, 블로그용 가중치(클릭 40·체류 43·전환 17)로 종합 |
| 빈틈 Top 3 | 가중치 × 부족분이 큰 트리거 3개와 바로 고칠 문장 예시 |
| 추상어·공급자어 | 규칙 30여 개로 탐지. `다양한 → 12가지`, `저희는 제공합니다 → 지금 바로 받아보세요` 같은 대안 제시 |
| 안전 치환 | 문법·군더더기만 자동 치환(사실을 새로 만드는 치환은 하지 않음). 실행 후 토스트에서 되돌리기 |
| 도입부 4종 | PAS(문제·자극·해결) · BAB(이전·이후·다리) · AIDA(주의·흥미·욕구·행동) · 4U(유용·긴급·독특·구체). 한국어 조사(은/는, 이/가, 을/를)를 받침으로 자동 선택 |

블로그 글은 구매 페이지가 아니라 희소성·구매 CTA가 낮은 것이 정상입니다. 그래서 종합 점수는 클릭·체류를 먼저 보도록 가중치를 다시 주고, 화면에도 그렇게 안내합니다. 점수는 참고 지표입니다.

## 내 구독 AI 원클릭 브리지

`engines/ai-bridge.js` — 프롬프트를 복사하고 새 창을 엽니다.

| 버튼 | 동작 |
| --- | --- |
| `ChatGPT 열기` | 프롬프트 복사 + `chatgpt.com/?q=…` (입력창 자동 입력) |
| `Claude 열기` | 프롬프트 복사 + `claude.ai/new?q=…` (입력창 자동 입력) |
| `Gemini 열기` | 프롬프트 복사 + `gemini.google.com/app` (붙여넣기) |

- 주소 자동 입력은 각 서비스가 공식 문서로 보장하지 않는 기능입니다. 로그인이 안 되어 있으면 빈 창이 열리므로 **항상 클립보드에도 복사**하고, 안 되면 `Ctrl+V`로 붙여넣으면 됩니다.
- 프롬프트가 길어 주소에 담기 어려우면(6,000자 초과 또는 인코딩 7,000자 초과) 자동 입력 대신 `붙여넣기` 배지로 안내합니다.
- **AI가 준 원고 → 90점 검수**: 답변을 통째로 붙여넣으면 첫 줄을 제목, 나머지를 본문, `태그:`·`#해시태그` 줄을 태그로 나눠 미리 점수를 보여 주고, 버튼 한 번으로 진단 탭에 넣어 기존 100점 채점을 돌립니다. 90점 이상이면 발행 준비 완료.
- **무료 Gemini API 키(선택)**: 키를 넣으면 새 창 없이 이 화면에서 원고를 받습니다. 키는 `localStorage`에만 저장되고 Google 주소로만 전송되며, 키가 비어 있으면 외부 요청은 0건입니다. 무료 티어는 프로젝트·모델에 따라 한도가 다르므로 오류 시 모델명을 바꿔 보세요.

```
apps/blog-seo-studio/
  index.html  styles.css  app.js  core.js  data.js
  engines/                     ← 이 앱만 복사해도 동작하는 독립 모듈
    copy-psych-engine.js       (packages/ 사본, 8대 트리거·4 프레임워크·교정)

  test.js  uitest.py
```

`engines/`에는 API 키도, 개인 블로그 주소도 들어 있지 않습니다(단위 테스트가 검사).

## 실행

정적 파일이라 `file://` 대신 간단한 HTTP 서버로 여세요.

```bash
cd apps/blog-seo-studio
python3 -m http.server 8080
# http://127.0.0.1:8080
```

## 테스트

```bash
NODE=/workspace/.local/lib/python3.12/site-packages/playwright/driver/node
$NODE test.js        # 단위 테스트
python3 uitest.py    # 실제 Chrome 1440×900 / 390×844
```

`uitest.py`는 콘솔 에러 0, 404 0, 가로 넘침 0을 확인하고 미리보기 PNG를 갱신합니다. Gemini API는 모의 응답으로 성공·한도 초과(429) 두 경로를 검증하며, ChatGPT·Claude 새 창은 실제 서비스에 접속하지 않고 주소만 확인합니다.

현재 결과: **단위 테스트 327개 통과 / 브라우저 체크 239개 통과** (2026-11-21).

## 설계 원칙

- **정직한 표기**: 내장 검색량은 예시 데이터이고, 업계 권장 수치(제목 28~42자, 2,000자, 4~8회)는 네이버 공식 기준이 아닙니다. 네이버가 공개한 금지어 목록도 없으므로, 검사는 법령·정책상 위험 표현과 품질 패턴을 잡는 참고 도구로 안내합니다. 심리 점수도 매출을 보장하지 않습니다.
- **순위는 수동**: 네이버 자동 순위 조회는 하지 않습니다. 직접 확인한 상태를 기록합니다.
- **키는 로컬**: 프록시·Gemini API 키는 브라우저에만 저장되고 사용자가 지정한 주소로만 전송됩니다. 외부 요청은 사용자가 버튼을 누를 때만 나갑니다.
- **사실은 만들지 않음**: 자동 교정은 문법·군더더기만 바꾸고, 수치·인증 같은 사실은 사용자가 채웁니다.
